Character Calibration & Weapon Restoration

October 28, 2026

Version 0.2.0 recalibrates character skin tones and hair, restores weapon specular details, corrects Dolphin DDS mipmap generation, and divides environment packages to stay under 2 GB.

Changes in v0.2.0:

  • Fina Character Calibrations: Rebalanced hand textures to match her natural skin tone, adjusted front bangs across 12 hair textures to match the golden-blonde crown lighting, and cleared murky shadow artifacts on her flared sleeves.
  • Aika Boomerang Restoration: Reconstructed starting boomerang handle textures by combining 4x pebbled leather detail with original specular amber highlights and silver rivets.
  • Vyse Twin Cutlasses Restoration: Restored polished steel wire hilt shine, warm wood grain, cutting edge specular sheens, and blade studs.
  • Dolphin DDS Mipmap Fix: Non-mipmapped surfaces now use strict single-mip flags (-m 1) to prevent Dolphin rejection errors; true mipmapped textures (_m_) retain full mip chains.
  • Environment Packages Under 2 GB: Split the environment assets into 4 packages (Overworld & Ships, Disc 1 Part 1, Disc 1 Part 2, and Disc 2) for easier downloading.

How to Install on Dolphin Emulator

Follow these steps to correctly apply the textures and ensure zero-stutter 60 FPS performance.

  1. Extract the files

    Download your desired .7z packages from the GitHub Releases page and extract them using 7-Zip (Windows) or The Unarchiver (macOS). Inside you will find the GEA folder.

  2. Move to Dolphin's Load Directory

    Copy the extracted GEA folder directly into Dolphin's texture directory. GEA is Dolphin's universal identifier for Skies of Arcadia Legends across all regional versions (NTSC-U GEAE01, PAL GEAP01, and NTSC-J GEAJ01).

    OS Directory Locations:
    • Windows: Documents\Dolphin Emulator\Load\Textures\GEA
    • macOS: ~/Library/Application Support/Dolphin/Load/Textures/GEA
    • Linux: ~/.var/app/org.DolphinEmu.dolphin-emu/data/dolphin-emu/Load/Textures/GEA (Flatpak) or ~/.local/share/dolphin-emu/Load/Textures/GEA

  3. Enable Custom Textures in Dolphin

    Open Dolphin and click on Graphics, then navigate to the Advanced tab. Under the Utility section, check the box for Load Custom Textures.

  4. Enable Prefetching (Crucial for Stutter-Free Play)

    Right underneath "Load Custom Textures", check the box for Prefetch Custom Textures. Because all files in this project are optimized as native BC7 DDS, prefetching streams them directly into your GPU's VRAM upon boot, eliminating in-game hitching and micro-stutters entirely.

    Recommended: Under Graphics → General, ensure your Backend is set to Vulkan or Direct3D 11 / 12 for peak performance.

Upscale Process

All texture assets are 4x their original size and perfectly optimized.

UI

Missing or compressed UI assets from the original Bighead and frozenwings project are recreated and redrawn from scratch for pixel-perfect clarity.

Character faces

Character faces are upscaled using Topaz Gigapixel AI's 'Redefine' generative model at 2x upscale, then 'High fidelity' model at 2x upscale. Textures are then carefully airbrushed in Photoshop to remove artifacts and enhance detail.

Character clothing

Character clothing is upscaled using Topaz Gigapixel AI's 'High fidelity' model at 4x upscale. Textures are then edited in Photoshop to enhance localized detail.

Weapons & Equipment

Party weapons (cutlasses, boomerangs, Cupil forms, arm cannons, and rapiers) are upscaled 4x with Topaz Gigapixel AI 'High fidelity', followed by manual Photoshop hand-painting to reconstruct metallic blade bevels, reflections, leather wraps, and crystal finishes.

Environment

Environment assets are upscaled using Topaz Gigapixel AI's 'Recover' generative model.

Special effects

Special effect textures (clouds, fire, shadows, lighting) are upscaled 4x in Adobe Photoshop and an appropriate Gaussian Blur filter is applied to smooth out harsh pixelation.
