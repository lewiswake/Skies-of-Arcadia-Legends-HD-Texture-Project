How to Install on Dolphin Emulator

Follow these steps to correctly apply the textures and ensure zero-stutter performance.

  1. Extract the files

    Download your desired .7z packages above and extract them using 7-Zip. You will see a folder named GEA (which is the GameCube ID for Skies of Arcadia Legends).

  2. Move to Dolphin's Load Directory

    Copy the extracted GEA folder and paste it into Dolphin's custom textures directory. Depending on your OS, this is usually located at:

    Documents\Dolphin Emulator\Load\Textures\

    The final folder path must look exactly like this: ...\Load\Textures\GEA

  3. Enable Custom Textures in Dolphin

    Open Dolphin and click on Graphics, then navigate to the Advanced tab. Under the Utility section, check the box for Load Custom Textures.

  4. Enable Prefetching (Crucial for Stutter-Free Play)

    Right underneath "Load Custom Textures", check the box for Prefetch Custom Textures. Because these files are optimized as BC7 DDS, prefetching will instantly load them into your GPU's VRAM, eliminating in-game hitching entirely.

Upscale Process

All texture assets are 4x their original size and perfectly optimized.

UI

Missing or compressed UI assets from the original Bighead and frozenwings project are recreated and redrawn from scratch for pixel-perfect clarity.

Character faces

Character faces are upscaled using Topaz Gigapixel AI's 'Redefine' generative model at 2x upscale, then 'High fidelity' model at 2x upscale. Textures are then carefully airbrushed in Photoshop to remove artifacts and enhance detail.

Character clothing

Character clothing is upscaled using Topaz Gigapixel AI's 'High fidelity' model at 4x upscale. Textures are then edited in Photoshop to enhance localized detail.

Environment

Environment assets are upscaled using Topaz Gigapixel AI's 'Recover' generative model.

Special effects

Special effect textures (clouds, fire, shadows, lighting) are upscaled 4x in Adobe Photoshop and an appropriate Gaussian Blur filter is applied to smooth out harsh pixelation.
