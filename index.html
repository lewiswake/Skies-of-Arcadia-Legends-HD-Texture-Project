Upscale Process

All texture assets are 4x their original size and perfectly optimized.

UI

Missing or compressed UI assets from the original Bighead and frozenwings project are recreated and redrawn from scratch for pixel-perfect clarity.

Character faces

Character faces are upscaled using Topaz Gigapixel AI's 'Redefine' generative model at 2x upscale, then 'High fidelity' model at 2x upscale. Textures are then carefully airbrushed in Photoshop to remove artifacts and enhance detail.

Character clothing

Character clothing is upscaled using Topaz Gigapixel AI's 'High fidelity' model at 4x upscale. Textures are then edited in Photoshop to enhance localized detail.

Environment

Environment assets are upscaled using Topaz Gigapixel AI's 'Recover' generative model.

Special effects

Special effect textures (clouds, fire, shadows, lighting) are upscaled 4x in Adobe Photoshop and an appropriate Gaussian Blur filter is applied to smooth out harsh pixelation.

Project Status: Distribution Phase

The project has successfully completed the Organization & Optimization phase. With nearly 17,000 files successfully processed, the focus is now on community distribution and flexible installation.

Completed Milestones

  • BC7 DDS Conversion: All PNG assets successfully converted to BC7 format, bypassing CPU decoding for zero-stutter Dolphin performance.
  • Modular Distribution: The monolithic 23GB project has been efficiently compressed and split into 6 distinct, downloadable packages.
  • Structure Clean-up: The folder hierarchy perfectly matches Dolphin's expected NTSC-U (`GEA`) structure for immediate plug-and-play functionality.
