How to Install on Dolphin Emulator

Follow these steps to correctly apply the textures and ensure zero-stutter 60 FPS performance on PC, Mac, Linux, and Steam Deck.

  1. Extract the files

    Download your desired .7z packages from the GitHub Releases page and extract them using 7-Zip (Windows) or The Unarchiver (macOS). Inside you will find the GEA folder.

  2. Move to Dolphin's Load Directory

    Copy the extracted GEA folder directly into Dolphin's texture directory:

    OS Directory Locations:
    • Windows: Documents\Dolphin Emulator\Load\Textures\GEA
    • Steam Deck (SteamOS):
    Flatpak default: ~/.var/app/org.DolphinEmu.dolphin-emu/data/dolphin-emu/Load/Textures/GEA
    EmuDeck path: /home/deck/Emulation/storage/dolphin/Load/Textures/GEA
    • Linux (Desktop): ~/.local/share/dolphin-emu/Load/Textures/GEA (Native) or ~/.var/app/org.DolphinEmu.dolphin-emu/data/dolphin-emu/Load/Textures/GEA (Flatpak)
    • macOS: ~/Library/Application Support/Dolphin/Load/Textures/GEA

    Steam Deck Note: In Desktop Mode, open Dolphin → Graphics → set Backend to Vulkan and Internal Resolution to 2x Native (720p/800p) for locked 60 FPS performance and great battery life.

  3. Enable Custom Textures in Dolphin

    Open Dolphin and click on Graphics, then navigate to the Advanced tab. Under the Utility section, check Load Custom Textures.

  4. Enable Prefetching (Crucial for Stutter-Free Play)

    Under Load Custom Textures, check Prefetch Custom Textures. Because all files in this project are optimized as native BC7 DDS, prefetching streams them directly into your GPU's VRAM upon boot, eliminating in-game hitching and micro-stutters entirely.

    Recommended: Under Graphics → General, ensure Backend is set to Vulkan or Direct3D 12.

  5. Recommended Dolphin Enhancements Settings

    For the best visual fidelity, optimal mipmap transitions, and authentic atmospheric rendering, configure your Dolphin Graphics → Enhancements tab:

    • Internal Resolution: 4x Native (2560x2112) for 1440p (or 2x–3x for Steam Deck / 1080p, 5x–6x for 4K)
    • Anti-Aliasing: 2x MSAA (or higher)
    • Texture Filtering: Force Linear and 16x Anisotropic
    • Scaled EFB Copy: Checked
    • Widescreen Hack: Checked (for 16:9 displays)
    • Disable Fog: Unchecked (fog must remain enabled for proper skybox depth and atmosphere)
    • Disable Copy Filter: Checked
    • Force 24-Bit Color: Checked
    • Arbitrary Mipmap Detection: Checked (crucial for custom hardware mipmaps)

v0.3.0

99% Complete HD Texture Overhaul

November 9, 2026

Version 0.3.0 brings the pack to 99% completion across the game world. Converted into Microsoft DirectX BC7 DDS format with full hardware mipmaps. While not all dumped game files are upscaled yet—mostly remaining UI assets with some environment effects still being tracked down—all major areas, characters, ships, and dungeons are remastered for stutter-free play.

Highlights in v0.3.0:

  • 99% Game Coverage (31,010 Textures): Massive overhaul covering party members, enemies, bosses, airships, towns, dungeons, overworld terrain, and battle stages.
  • Streamlined Folder Hierarchy: All asset folder paths shortened down to concise Model IDs, preventing Windows MAX_PATH (260-char) overflow crashes in modern recompilers.
  • BC7 DDS Format & Zero Stutter: Textures prefetch directly into GPU VRAM in Dolphin, eliminating CPU runtime decoding hitching and frame spikes.
  • Alpha Transparency & Ghost Haze Audit: Systematic cleanup of low-alpha edge fringing (1 ≤ α ≤ 25) to eliminate gray bounding-box outlines on character cutouts and foliage.
  • Atmospheric Smoothing Pipeline: Proportional Gaussian blur applied strictly to alpha channels for transparent particles and haze (smoke, clouds, mist, fog).
  • Runtime GPU Aliases: Dual _arb.dds compatibility naming for dynamic runtime paletted textures.

Process

Upscaling methods

Characters — Faces, Clothing and Weapons

Faces were upscaled with Topaz Gigapixel Redefine tool at 2x and low creativity settings to generate higher resolution textures. Face textures were then upscaled in Topaz Gigapixel with the High Fidelity model at 2x, minimal sharpen, high denoise, and high compression fix. This results in a smooth upscaled version close to the original artistic direction of the base assets. Any assets that require airbrushing and tweaking are processed in Photoshop in post. This is an ongoing project. Characters body and clothing textures are largely upscaled with Topaz Gigapixel High fidelity model at 4x.

Environment

Rock and stone textures upscaled with Topaz Gigapixel Recover generative model. Natural foliage is upscaled with high fidelity model in Topaz Gigapixel.

UI and Fonts

UI and Fonts were largely carried over from the original Bighead and frozenwings project. Assets that were left unfinished have been worked on by Shoopkid (ie. Cupil Cham alert, Moonfish target, Delphinus compass, Battle UI Captain Command Icon.) Mostly redrawn entirely from scratch in Photoshop and Procreate when required. Original base textures are brought into either Photoshop or Procreate, upscaled 4x and then I redraw or recompose them using that as a foundation.

Effects — Shadows, Fires, Glowing Assets

Special effect textures (clouds, smoke, fire, shadows, lighting) are upscaled 4x with Gaussian blur applied strictly to the alpha channel to eliminate harsh pixelation without gradient loss. These are the hardest to upscale as the way the Gamecube engine can read transparency textures is hit or miss. I have found that Photoshop upscaled 4x then applying a gaussian blur of 10px radius is most effective at achieving a successful upscale.
