Upscale Process

All texture assets are 4x their original size.

UI

Missing UI assets from the original Bighead and frozenwings project are recreated and redrawn from scratch.

Character faces

Character faces are upscaled using Topaz Gigapixel AI's 'Redefine' generative model at 2x upscale, then 'High fidelity' model at 2x upscale. Textures are then airbrushed in Photoshop to remove artifacts and enhance detail.

Character clothing

Character clothing is upscaled using Topaz Gigapixel AI's 'High fidelity' model at 4x upscale. Textures are then edited in Photoshop to enhance detail.

Environment

Environment assets are upscaled using Topaz Gigapixel AI's 'Recover' generative model. RIP my GPU...

Special effects

Special effect textures (clouds, fire, shadows, lighting) are upscaled 4x in Adobe Photoshop and an appropriate Gaussian Blur filter is applied to smooth out pixelation.
